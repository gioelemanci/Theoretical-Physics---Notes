# Theoretical Physics Master's Notes — UniBo

This repository contains the personal lecture notes and $\LaTeX$ source code I wrote for myself while attending the **Master's Degree in Physics (Theoretical Physics curriculum)** at the **University of Bologna (UniBo)**. I'm sharing them here in case they can be helpful to other students.

Each folder contains both the $\LaTeX$ project (`chapters`, `preamble`, `img`, `appendix`, and `main.tex`) and the compiled `main.pdf`.

## ⚠️ Disclaimer

These are **unofficial student notes** written for personal study and have **not** been reviewed by the professors. They almost certainly contain typos, sign errors, or imprecise statements. Always cross-check with official textbooks and lecture material.

## 🛠️ Typos & Corrections

If you are using these notes and spot a mistake, any help in fixing it is welcome:

* You can open an **Issue** specifying the course, page number, and equation.
* Or, since the $\LaTeX$ source code is included, feel free to edit the `.tex` files inside `chapters/` and open a **Pull Request**.
